## 2. Event Payload Details

### EditStartedEvent
| Field | Description | When Set |
|-------|-------------|----------|
| `EventId` | Unique GUID | Always |
| `ItemKey` | Row identifier | From `GetItemKey(item)` |
| `PropertyName` | Column property | From `_propertyName` |
| `Timestamp` | Event time | `DateTimeOffset.Now` |
| `CurrentValue` | Value at focus time | From `_currentValues[itemKey]` |

### EditCommittedEvent
| Field | Description | When Set |
|-------|-------------|----------|
| `EventId` | Unique GUID | Always |
| `ItemKey` | Row identifier | From `GetItemKey(item)` |
| `PropertyName` | Column property | From `_propertyName` |
| `Timestamp` | Event time | `DateTimeOffset.Now` |
| `OldValue` | Value before edit | From `_originalValues[itemKey]` |
| `NewValue` | Value after edit | From parameter |

### EditCancelledEvent
| Field | Description | When Set |
|-------|-------------|----------|
| `EventId` | Unique GUID | Always |
| `ItemKey` | Row identifier | From `GetItemKey(item)` |
| `PropertyName` | Column property | From `_propertyName` |
| `Timestamp` | Event time | `DateTimeOffset.Now` |
| `OriginalValue` | Reverted value | From `_originalValues[itemKey]` |
| `AttemptedValue` | Discarded value | From `_currentValues[itemKey]` |

### ValidationSucceededEvent
| Field | Description | When Set |
|-------|-------------|----------|
| `EventId` | Unique GUID | Always |
| `ItemKey` | Row identifier | From `GetItemKey(item)` |
| `PropertyName` | Column property | From `_propertyName` |
| `Timestamp` | Event time | `DateTimeOffset.Now` |
| `Value` | Validated value | From parameter |
| `RuleResults` | Validator outcomes | All rules with `IsValid=true` |

### ValidationFailedEvent
| Field | Description | When Set |
|-------|-------------|----------|
| `EventId` | Unique GUID | Always |
| `ItemKey` | Row identifier | From `GetItemKey(item)` |
| `PropertyName` | Column property | From `_propertyName` |
| `Timestamp` | Event time | `DateTimeOffset.Now` |
| `AttemptedValue` | Invalid value | From parameter |
| `Errors` | Error messages | From failed validators |
| `RuleResults` | Validator outcomes | All rules with status |
