# About this document

This document provides an overview of the Command Line Interface (CLI) and the description of all the available commands for managing the 1830 GX Nokia network element.

## Audience

This document is intended for personnel responsible for operating, maintaining and administrating the Nokia 1830 GX network element using the Command Line Interface (CLI). Personnel performing these tasks must understand basic networking concepts, and have a good knowledge of optical layers technology. Personnel must also comply with all relevant safety practices whenever working with 1830 GX equipment ( 1830 GX G30 equipment refers to 1830 GX G31, 1830 GX G32 and 1830 GX G34c equipment chassis; and 1830 GX G40 equipment refers to 1830 GX G42 equipment chassis).
