## 6.150. KRK

#### Command Description

These commands are used to show the list of Image Root Keys (KRKs) list and KRK information.

#### Command Syntax

```
show KRK-<name> [CPU] [key-name] [key-serial-number] [issuer-name] [key-length] [key-payload]
show KRKs
```

#### Command Usage Details

**Table 389: KRK Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 390: KRK Command Flags**

| Parameter | Description |
| --- | --- |
| -f | Forces the command without confirmation. |

**Table 391: KRK Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| name | Unique representation of the object. | String | n/a | show |
| CPU | Identifier for member CPUs on cards starts at 0. | Number (uint8) | n/a | show |
| key-name | Name of the key. | String (length 0..64) | n/a | show |
| key-serial-number | Key Serial Number. | String | n/a | show |
| issuer-name | Name of the CSA (Code Signing Appliance). | String (length 0..20) | n/a | show |
| key-length | Key length in bits. | Number (uint16) | n/a | show |
| key-payload | Key Payload (hex format). | String (length 0..1100) | n/a | show |

#### Examples

This example shows how to view one Image Root Key (KRK) from the system:

```
show KRK-1-5-0-KRK_E1
```

This example shows how to view the Image Root Key (KRK) list from the system:

```
show KRKs
```
