## 6.229. otu

#### Command Description

These commands are used to add, edit or show an OTU. The delete command is used to remove an OTU from the configuration.

#### Command Syntax

```
add otu-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [fec-mode <value>] [fec-generation-mode <value>] [fec-type
<value>] [tx-mapping-mode <value>] [expected-mapping-mode <value>] [loopback <value>] [loopback-mode <value>] [parent <value>] [time-slots
<value>]
set otu-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [fec-mode <value>] [fec-generation-mode <value>] [fec-type
<value>] [tx-mapping-mode <value>] [expected-mapping-mode <value>] [loopback <value>] [loopback-mode <value>] [time-slots <value>]
show otu-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [otu-type] [rate] [otu-name] [service-mode] [service-mode-qualifier] [fec-mode]
[fec-generation-mode] [fec-type] [tx-mapping-mode] [expected-mapping-mode] [loopback] [loopback-mode] [circuit-id] [parent] [time-slots]
delete otu-<name>
```

#### Examples

This example shows how add an OTUC4 with alarm reporting enabled:

```
set otu-OTUC4 alarm-report-control enabled
```

This example shows how to add line side OTU4 on GX G40 network element:

<!-- page 903 -->

```
add otu-1-5-L1-1-OTU4-1 parent flexo-group-1-5-L1-1 time-slots 1
```
