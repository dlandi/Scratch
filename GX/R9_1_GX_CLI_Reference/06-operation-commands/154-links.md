## 6.154. links

#### Command Description

This command is used to show the links container within the topology. These links are dynamically filled in by the system, allowing to derive and display the NCT topology.

#### Command Syntax

```
show links
```

#### Command Usage Details

**Table 397: links Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.
