## 6.287. set

#### Command Description

The `set` assigns values to the specified attributes. This command changes the values of the attributes of existing managed entities. The command requires at least one attribute-value pair, but multiple pairs can be provided, as long as they belong to the same managed entity. Additionally, one or multiple filters may be provided to affect only matching entities. If no entity id is provided, the currently scoped entity will be used. It is possible to set an attribute in multiple instances simultaneously by using wildcards (\*):

- as replacement of the whole instance key (card-\*)
- as replacement of a single instance key (port-1-4-\*; port-1-\*-3)
- as replacement of all following (to the right) keys (odu-1-4,5,6,7-\*)
- for auto-completing instance keys (user-admin\*; ethernet-\*)
- for auto-completing attribute names (admin\* instead of admin-state)

For more information about wildcard usage, refer to CLI Wildcard support (p. 84). It is also possible to use [] to represent ranges (card-1-[1..4]) or lists (interface-[DCN,CRAFT]; trib-ptp-[1-4-T1,1-6-T16,1-7-T15]). For inputting string values:

- use quotes for inputting multi word strings
- use '\n' to represent new lines
- use quotes if the string contains the comment symbol (#).

This command will ask for confirmation:

- when the request may have traffic impact
- when the request is implicitly affecting multiple instances

**Tip:** Use '?' (contextual help) for hints on what is the expected value type for a given attribute.

#### Command Syntax

```
set -h
set [-f|-v] [<entity id>] <attribute> <value> [<attribute> <value> ...] [<filter> ...]
```

#### Examples

This example shows how to set attribute ne-location to the value 'London':

```
set ne-location London
```

This example shows how to set the attribute warning-message with multi-word value:

```
set ssh post-login-message 'Hello World!'
```

This example shows how to test whether it is possible to set attribute ne-location to value 'Paris':

```
set -v ne-location Paris
```

This example shows how to set the value of attribute admin-state to 'lock' for all line ports:

```
set port port-type=line admin-state lock
```

This example shows how to enable15min and 24hr historical PMs for all resources:

```
set pm-control-entry data-supervision true
```

This example shows how to set all ports on card-1-4 to admin-state=lock :

```
set port-1-4* admin-state lock
```

This example shows how to set the label for CHM6 card card-1-6:

```
set card-1-6 label Test
```

This example shows how to lock CHM6 card card-1-5:

```
set card-1-5 admin-state lock
```

This example shows how to set a tom's label to "infinera" :

```
set tom-1-4-T1 label infinera
```

This example shows how to change the subtype of a card to C6, the remaining card configuration is unchanged.:

```
set card-1-4 required-subtype C6
```

This example shows how to associate a leaf certificate to secure-application:

<!-- page 1084 -->

```
set secure-application-WebGUI active-certificate-id client
```
