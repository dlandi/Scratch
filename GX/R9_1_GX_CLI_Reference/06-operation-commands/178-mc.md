## 6.178. mc

#### Command Description

These commands are used to add, delete the Media Channel (MC), and set or show the MC facility attributes.

#### Command Syntax

```
add mc-<name> parent-oms <value> lower-frequency <value> upper-frequency <value> [label <value>] [admin-state <value>] [alarm-report-control
<value>] [auto-delete <value>]
set mc-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [parent-oms &lt;value&gt;] [lower-frequency &lt;value&gt;]
[upper-frequency &lt;value&gt;] [auto-delete <value>]
show mc-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [parent-oms] [center-frequency] [lower-frequency] [upper-frequency] [slot-width] [auto-delete]
delete mc-<name>
```

#### Examples

This example shows how to create a Media Channel (MC):

```
add mc-1-3.1-dwdm-line-192262500 parent-oms '1-3.1-dwdm-line' lower-frequency '192225000' upper-frequency '192300000'
```
