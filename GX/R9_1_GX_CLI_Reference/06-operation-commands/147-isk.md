## 6.147. ISK

#### Command Description

The show command is used to view the Image Signing Key (ISK) resources from the system. The clear command is used to remove one particular ISK from the system. The name of the key to be deleted needs to be provided.

#### Command Syntax

```
clear [-f] isk [key-name=]<value>
show ISK-<name> [CPU] [key-name] [key-serial-number] [issuer-name] [key-length] [key-payload] [is-key-in-use] [is-key-verified] [being-deleted]
[KRK-name] [signature-hash-scheme] [signature-algorithm] [signature-payload] [signature-gen-time]
show ISKs
```

#### Command Usage Details

**Table 382: ISK Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode (only for show command) |

#### Command Parameters

**Table 383: ISK Command Flags**

| Parameter | Description |
| --- | --- |
| -f | Forces the command without confirmation. |

**Table 384: ISK Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| name | Unique representation of the object. | String | n/a | show |
| CPU | Identifier for member CPUs on cards starts at 0. | Number | n/a | show |
| key-name | The name of the Image Signing Key (ISK) resource. The name of the key to be deleted needs to be provided. | String (length 0..64) | n/a | clear, show |
| key-serial-number | Key Serial Number. A list of carriers that are bound to this resource. | String | n/a | show |
| issuer-name | Name of the CSA (Code Signing Appliance). | String (length 0..20) | n/a | show |
| key-length | Key length in bits. | Number (bits) | n/a | show |
| key-payload | Key Payload (hex format). | String (length 0..1100) | n/a | show |
| is-key-in-use | Indicates if the key is in use in this FRU. | true, false | false | show |
| is-key-verified | Indicates if the key is verified in this FRU. | true, false | false | show |
| being-deleted | If the system is in the process of deleting this ISK, it is set to true. Otherwise, it is set to false. This is set to true once the system gets an ISK delete command. This indicates that the system is in the process of deletion and will soon delete this ISK. | true, false | n/a | show |
| KRK-name | Name of the KRK (Image root key) that signed this ISK. | String | n/a | show |
| signature-hash-scheme | Hashing Scheme | SHA2 256 _ SHA2 384 _ SHA2 512 _ | n/a | show |
| signature-algorithm | Signature Algorithm. | ECDSA RSA none | n/a | show |
| signature-payload | Signature Payload. | String (length 0..1024) | n/a | show |
| signature-gen-time | Signature Generation Time. | date and time | n/a | show |

#### Examples

This example shows how to view one Image Signing Key (ISK) from the system:

```
show ISK-1-5-0-ISK_E1
```

This example shows how to view the Image Signing Key (ISK) list from the system:

```
show ISKs
```

This example shows how to clear the Image Signing Key (ISK) from the system:

```
clear isk key-name=name
```
