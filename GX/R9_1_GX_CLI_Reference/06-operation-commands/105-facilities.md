## 6.105. facilities

#### Command Description

This command is used to show system facilities.

#### Command Syntax

```
show facilities
```

#### Command Usage Details

**Table 297: facilities Command Usage**

| Section | Description |
| --- | --- |
| User Access Privilege Level | Operational mode, Candidate Configuration Mode |

#### Command Parameters

None.

#### Examples

This example shows how to display the available facilities in a 1830 GX G40 node:

```
show facilities
  facilities
  super-channel-group-1-4-L1
  super-channel-group-1-4-L2
  super-channel-1-4-L1-1
  super-channel-1-4-L2-1
  optical-carrier-1-4-L1-1
  optical-carrier-1-4-L2-1
  optical-channel-1-4-L1-1
  optical-channel-1-4-L2-1
  trib-ptp-1-4-T11
  trib-ptp-1-4-T13
  trib-ptp-1-4-T2
  trib-ptp-1-4-T8
  comm-channel-1-4-L1-1
  comm-channel-1-4-L2-1
  otu-1-4-L1-1-OTUCni
  otu-1-4-L2-1-OTUCni
  otu-1-4-T11
  otu-1-4-T13
  ethernet-1-4-T2
  ethernet-1-4-T8
  odu-1-4-L1-1-ODUCni
  odu-1-4-L2-1-ODUCni
  odu-1-4-L2-1-ODUflexi-1
  odu-1-4-T11
  odu-1-4-T13
  odu-raja
```
