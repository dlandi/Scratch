## 6.250. protection

#### Command Description

This command is used to show protection.

#### Command Syntax

```
show protection
```

#### Command Usage Details

**Table 593: protection Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

This example shows how to view the protection setting:

```
show protection
```
