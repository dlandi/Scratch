## 6.374. ztp

#### Command Description

This command shows the Zero Touch Provisioning (ZTP) status. Refer to change-ztp-mode (p. 289) for ZTP configuration.

#### Command Syntax

```
show ztp [ztp-mode] [ztp-state] [ztp-details] [ztp-completion-status]
```

#### Command Usage Details

**Table 855: ztp Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 856: ztp Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| ztp-mode | User-set mode of ZTP. This flag is set via change-ztp-mode RPC that is allowed even when NBI is locked. | disabled, enabled | enabled | show |
| ztp-state | Current state of ZTP service. | ztp-init dhcp-in-progress image-download-in-progress image-install-in-progress custom-script-execution-in-progress multi-chassis-setup-in-progress configuration-apply-in-progress ztp-completed ztp-state-unknown ztp-disabled wait-before-ztp-restart | ztp-init | show |
| ztp-details | Additional information on the current state. | String (length 0..256) | n/a | show |
| ztp-completion-status | Summarized completion status of ZTP on the node. | not-completed completed | not-completed | show |

#### Examples

This example shows how to view ZTP attributes:

```
show ztp
```
