## 6.95. est

#### Command Description

The Enrollment over Secure Transport (EST) protocol enables robust and automated certificate management, allowing devices to handle certificate requests, renewals, and management securely via HTTPS. The device includes an EST client designed to communicate with the dedicated EST server. EST significantly improves efficiency by providing an optimized, automated workflow that replaces the complex, manual steps of the traditional Certificate Signing Request (CSR) process.

#### Command Syntax

```
est [target-command=]<value> [[est-ca=]<value>] [certificate-name=]<value> ([[key-algorithm=]<value>] | [[key-from-certificate=]<value>])
[[signature-hash-algorithm=]<value>] [[metadata-template=]<value>] [metadata-from-certificate=]<value> [metadata-from-cnf=]<value>
[[subject=]<value>] [[SAN=]<value>] [[key-usage=]<value>[,<value>]*] [[extended-key-usage=]<value>[,<value>]*] [[http-user=]<value>]
[[http-password=]<value>]
```

#### Examples

- The following example shows how to enroll a new certificate using HTTP credentials when a valid mTLS certificate does not exist:

```
est enroll certificate-name=myNewCertificateA subject='/CN=NewCertA' http-user=<username> http-password=<password>
```
