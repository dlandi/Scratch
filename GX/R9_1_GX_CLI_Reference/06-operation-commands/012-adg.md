## 6.12. adg

#### Command Description

These commands are used to add, delete an Add/Drop Group (ADG) and to set or show the ADG attributes.

#### Command Syntax

```
set adg-<adg-number> [label <value>]
show adg-<adg-number> [label] [max-add-drop-ports] [wavelength-duplication] [bands-supported]
delete adg-<adg-number>
```

#### Command Usage Details

**Table 93: adg Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 94: adg Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| adg-number | ADG identifier as a number. | integer in the range [1..110] | n/a | add, set, show, delete |
| label | User defined label. | String (length: 0..256) | n/a | add, set, show |
| max-add-drop-ports | The max number of ports available for a given ADG. | integer | n/a | show |
| wavelength-duplication | Whether the SRG can handle duplicate wavelengths and if so to what extent. Only CDCs allow more than one instance of the same wavelength on the ADG. | • one-per-adg - No duplication of frequencies in the ADG.<br>• one-per-degree - CDC: duplication of frequencies allowed in the ADG, but only one at the Degree. | one-per-adg | show |
| bands-supported | List of bands supported by an ADG, with dependence on supported cards.<br>• not-applicable -Transmission band not applicable.<br>• standardC-band - Standard C-band (4.85 THz).<br>• superC-band - SuperC-band (6.1 THz).<br>• standardL-band - Standard L-band (4.85 THz).<br>• standardC-standardL-band - Standard C or Standard L band. | • not-applicable<br>• standardC-band<br>• superC-band<br>• standardL-band<br>• standardC-standardL-band | standardC-band | show |

#### Examples

This example shows how to add an ADG:

```
add adg-1
```
