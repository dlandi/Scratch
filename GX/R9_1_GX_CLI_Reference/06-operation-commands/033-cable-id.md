## 6.33. cable-id

#### Command Description

The commands described in this section are used to show the `cable-id` entities and terminate a CableID verification test. For additional information on the terminate cable-id command, refer to terminate (p. 1274).

#### Command Syntax

```
show cable-id
terminate cable-id
```

#### Command Usage Details

**Table 137: cable-id Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode (only for show command) |

#### Command Parameters

None.

#### Examples

The following command shows how to view all the cableID entities:

```
show cable-id
```

The following command shows how to terminate all the running cableID verification tests:

```
terminate cable-id
```
