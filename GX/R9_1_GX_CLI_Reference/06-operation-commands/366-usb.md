## 6.366. usb

#### Command Description

This command shows the USB function attributes of the port.

#### Command Syntax

```
show usb-<card-name>-<port-name> [type] [present] [available-space] [total-space] [usb-path]
```

#### Command Usage Details

**Table 840: usb Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 841: usb Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| card-name | Name of the card with USB port. | String | n/a | show |
| port-name | Name of the USB port. | String | n/a | show |
| type | The role of the usb port. storage - USB port can be used for file storage, and supports associated file management operations power-supply - USB port can be used to power additional external equipment (for example, passive shelves) | storage power-supply | n/a | show |
| present | Indicates the presence state of the USB connector. | true, false | false | show |
| available-space | The current available storage space in the file-system associated with this USB port. Applicable if the type is storage. | uint16 (MB) | n/a | show |
| total-space | The total storage space available in the file-system associated with this USB port. Applicable if the type is storage. | uint16 (MB) | n/a | show |
| usb-path | Local filesystem path on where this USB file-system is mounted; this can be used as a target/ source for file transfer operations. Applicable if the type is storage. | String (length 0..32) | n/a | show |

#### Examples

This example shows how to view the USB port attributes from FRCU card:

```
show usb-1-5-U1
```

This example shows how to display the USB ports information available in the node:

```
show usb
```

The following output is displayed:

```
show usb
usb         type          present
----------  ------------  -------
usb-1-1-U1  storage       false
usb-1-2-U1  power-supply  false
usb-1-2-U2  power-supply  false
```
