## 6.234. peer-certificate

#### Command Description

These commands are used to set or show the attributes of the X509v3 end-entity certificate that represents a trusted 'remote peer' certificate for L1 encryption secure application.

#### Command Syntax

```
set peer-certificate[-id] [alarm-report-control <value>] [label <value>] [revocation-mode <value>]
show peer-certificate[-id] [version] [serial-number] [subject-name] [issuer] [trust-chain] [valid-from] [valid-to] [status] [public-key-length]
[public-key-type] [signature-key-type] [signature-hash-algorithm] [certificate-bytes] [subject-alternative-names] [white-listed]
[alarm-report-control] [label] [key-usage] [extended-key-usage] [modification-time] [revocation-mode]
```

#### Examples

This example shows how to show the attributes of the peer-certificate with ID cert:

```
show peer-certificate-cert
```

This example shows how to set the peer-certificate alarm-report-control to inhibited:

```
set peer-certificate-cert alarm-report-control inhibited
```

This example shows how to allow a trusted-certificate alarm reporting:

```
set trusted-certificate-root alarm-report-control allowed
```
