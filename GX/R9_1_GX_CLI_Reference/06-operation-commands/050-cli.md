## 6.50. cli

#### Command Description

These commands are used to set or show the configuration of the Command Line Interface (CLI) management protocol.

#### Command Syntax

```
set cli [enabled <value>] [port <value>] [default-interactive-mode <value>] [show-alarm-columns <value>]
show cli [enabled] [port] [script-dir] [default-interactive-mode] [show-alarm-columns]
```

#### Command Usage Details

**Table 175: cli Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 176: cli Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| enabled | Enables/disables the CLI management protocol. It is not possible to disable CLI from within a CLI session. | true false | true | set, show |
| port | The port which listens for CLI access via ssh. | Number (range: 1..65535) | 22 | set, show |
| script-dir | Location in the filesystem where CLI scripts are stored. | String (length 1..80 characters) | n/a | show |
| default-interactive-mode | Defines whether CLI sessions have interactive-mode enabled or disabled by default. Note: changing this parameter will not affect existing CLI sessions, only newly created sessions. | • true<br>• false | true | set, show |
| show-alarm-columns | Columns to display in the output of 'show alarm' CLI command. Possible values:<br>• list of columns, separated by a comma ','.<br>• default-columns, show the pre-defined columns.<br>• default-columns,&lt;additional-details&gt;, to show the &lt;additional-details&gt; column for the pre-defined columns. This configuration has a global effect, it takes effect on all CLI sessions. | • list of columns, separated by a comma ','.<br>• default-columns<br>• default-columns,&lt;add itional-details&gt; | default-columns | set, show |

#### Examples

The following example shows all cli attributes:

```
show cli
```

The following example shows the cli port attribute:

```
show cli port
```

The following example shows how to set the output of 'show alarm' CLI command to show only columns col1, col2 and col3:

```
set cli show-alarm-columns col1,col2,col3
```

The following example shows how to set the output of 'show alarm' CLI command to show the corrective-action column as the last column:

```
set cli show-alarm-columns default-columns,corrective-action
```

The following example shows how to enable the CLI management protocol:

<!-- page 312 -->

```
set cli enabled true
```

The following example shows how to set the CLI port to port 22:

```
set cli port 22
```
