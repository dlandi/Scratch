## 6.372. vrf

#### Command Description

This command shows the Virtual Routing and Forwarding (VRF) instance.

#### Command Syntax

```
show vrf-<name> [type] [chassis-name] [description]
```

#### Command Usage Details

**Table 851: vrf Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 852: vrf Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| description | Description of the VRF and its intended purpose. | String (length 0..255) | n/a | show |
| name | Name of the VRF. | String (length 0..32) | n/a | show |
| type | VRF type. mgmt - Management VRF internal - Internal VRF | mgmt internal | n/a | show |
| chassis-name | Associated chassis name to this VRF. | chassis name | n/a | show |

<!-- page 1349 -->

#### Examples

The following example shows how to view the Management VRF attributes:

```
show vrf-MGMT
```
