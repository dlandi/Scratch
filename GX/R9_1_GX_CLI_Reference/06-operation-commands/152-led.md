## 6.152. led

#### Command Description

These commands are used to show the representation of a LED in a FRU. Object exists even if FRU is not physically present.

#### Command Syntax

```
show led-<location>/<name> [status]
show leds
```

#### Command Usage Details

**Table 393: led Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 394: led Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| location | The location of the FRU, that is, the AID of equipment location of the LED (may be a chassis, card or a port AID). | String (length 1..32) | n/a | show |
| name | Name of the LED within the FRU. | String (length 1..16) | n/a | show |
| status | The state of the LED, that is, the current color status of the LED: not-available - LED status not available. off - LED is turned off and has no color. yellow - LED is turned on with yellow color. flashing-yellow - LED is flashing, alternating between off and yellow color. green - LED is turned on with green color. flashing-green - LED is flashing, alternating between off and green color. red - LED is turned on with red color. flashing-red - LED is flashing, alternating between off and red color. cycling-with-off - LED is cycling between all supported colors, including off state. cycling - LED is cycling between all supported colors (excluding off state) - used for lamp test. amber - LED is turned on with amber color. flashing-amber - LED is flashing, alternating between off and amber color. | not-available off yellow flashing-yellow green flashing-green red flashing-red cycling-with-off cycling amber flashing-amber | not-available | show |
