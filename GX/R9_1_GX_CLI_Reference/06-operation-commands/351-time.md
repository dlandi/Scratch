## 6.351. time

#### Command Description

This command is used to display the system's time.

#### Command Syntax

```
time
```

#### Command Usage Details

**Table 808: time Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

None.

#### Examples

This example shows how to view the system time:

```
time
```

The following output is displayed:

```
2020-06-29T22:29:37+00:00
```
