## 6.6. ace

#### Command Description

This command is used to add/set attributes associated with every access control entry (ACE). An ACL can have one or more ACEs. Use the delete command to delete an ACE from the configuration.

**Tip:** To add an ACE, at least one of these parameters - Source IP / Destination IP / L4 ports / TTL / protocol needs to be provided.

**Note:** It is recommended to use distinct values for source upper-port and lower-port, as well as for destination upper-port and lower-port when adding an ACE. A maximum of 16 ACEs can be created on an ACL if both upper-port and lower-port values are specified. If an attempt is made to add another ACE with both values specified when 16 ACEs already exist on the ACL, an error message will be displayed.

**Tip:** The supported range for sequence-id is 1-100 for AUX and DCN-B interfaces and 1-256 for DCN-A interface. It is recommended to have the sequence-id in multiples of 5. This is done to allow users to insert rules if needed.

#### Command Syntax

```
add ace-<name>/<sequence-id> [label <value>] [direction <value>] [logging-action <value>] [source-ip-address <value>] [source-lower-port <value>]
[source-upper-port <value>] [destination-ip-address <value>] [destination-lower-port <value>] [destination-upper-port <value>] [ttl <value>]
[action <value>] [protocol <value>]
set ace-<name>/<sequence-id> [label <value>] [direction <value>] [logging-action <value>] [source-ip-address <value>] [source-lower-port <value>]
[source-upper-port <value>] [destination-ip-address <value>] [destination-lower-port <value>] [destination-upper-port <value>] [ttl <value>]
[action <value>] [protocol <value>]
show ace-<name>/<sequence-id> [label] [direction] [logging-action] [source-ip-address] [source-lower-port] [source-upper-port]
[destination-ip-address] [destination-lower-port] [destination-upper-port] [ttl] [action] [protocol]
delete ace-<sequence-id>
```

**Table 70: ace Command Usage**

#### Command Parameters

**Table 71: ace Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| sequence-id | Sequence number that establishes the relative order of the ACE within an ACL | range<br>• AUX and DCN-B interfaces - 1 - 100<br>• DCN-A interface - 1 - 256 | n/a | add, set, delete, show |
| action | The action taken by the filter. | drop, accept, reject | drop | add, set, show |
| destination-ip-address | Specifies the destination IP of this filter. | ipv4 address, ipv6 address | n/a | add, set, show |
| destination-lower-port | The lower bound on the destination Layer 4 TCP/UDP port number | port number | 0 | add, set, show |
| destination-upper-port | The upper bound on the destination Layer 4 TCP/UDP port number | port number | 0 | add, set, show |
| direction | Specifies whether this filter is applied to incoming packets or outgoing packets. | input, output | input | add, set, show |
| interface | The interface to which the ACE is added. | string | n/a | add, set, show |
| logging-action | Flag to indicate if logging needs to be done once the ACE rule is matched. | true, false | false | add, set, show |
| protocol | The internet protocol number. | ah, any, comp, egp, \|esp, gre, icmp, idrp, igmp, igrp, isis, ospf, rspv, tcp, udp, vrrp | any | add, set, show |
| source-ip-address | Specifies the source IP of this filter. | ipv4 address, ipv6 address | n/a | add, set, show |
| source-lower-port | The lower bound of the source Layer 4 TCP/UDP port number. | port number | 0 | add, set, show |
| source-upper-port | The upper port bound of the source Layer 4 TCP/UDP port number. | port number | 0 | add, set, show |
| label | User-defined label. | string | n/a | add, set, show |
| ttl | IPv4 and IPv6 packet's time-to-live (TTL) hop limit. | Range (1...255) | 255 | add, set, show |
| label | User-configurable label. | string (length 1...255) | n/a | add, set, show |

#### Examples

This example shows how to add an ACE. (The ACL must be in created first before adding an ACE to the ACL.):

```
add ace-TrafficV6/100 action drop source-ip-address 2420::5
```
