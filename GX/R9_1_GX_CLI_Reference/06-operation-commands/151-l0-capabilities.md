## 6.151. l0-capabilities

#### Command Description

The command described in this section is used to show the capabilities details related with node's Layer 0 functions.

#### Command Syntax

```
show l0-capabilities
```

#### Command Usage Details

**Table 392: l0-capabilities Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

None.

#### Examples

The following example shows how to display the L0 capabilities:

```
show l0-capabilities
```
