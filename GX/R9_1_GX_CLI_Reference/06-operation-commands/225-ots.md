## 6.225. ots

#### Command Description

These commands are used to set or show the Optical Transport Section (OTS) facility attributes.

#### Command Syntax

```
set ots-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [osc-compatibility <value>] [enable-dcn-interworking
<value>] [osc-less <value>] [fiber-type-rx <value>] [fiber-type-tx <value>] [fiber-length-tx <value>] [fiber-length-rx <value>]
[fiber-spectral-attenuation-tilt-tx <value>] [fiber-spectral-attenuation-tilt-rx <value>] [raman-coefficient-tx <value>] [raman-coefficient-rx
<value>] [span-loss-reference <value>] [span-loss-transmit <value>] [span-loss-receive <value>] [external-attenuation-tx <value>]
[external-attenuation-rx <value>] [span-loss-aging-margin-rx <value>] [target-power-setting <value>] [target-power-adjust-cband <value>]
[target-power-adjust-lband <value>] [loading-policy <value>]
show ots-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [osc-compatibility] [enable-dcn-interworking] [osc-less-support] [osc-less] [fiber-type-rx]
[fiber-type-tx] [fiber-length-tx] [fiber-length-rx] [fiber-length-derived-rx] [fiber-length-derived-tx] [fiber-spectral-attenuation-tilt-tx]
[fiber-spectral-attenuation-tilt-rx] [raman-coefficient-tx] [raman-coefficient-rx] [span-loss-reference] [span-loss-alarm-threshold]
[span-loss-transmit] [span-loss-receive] [span-loss-derived-rx] [span-loss-derived-tx] [external-attenuation-tx] [external-attenuation-rx]
[span-loss-aging-margin-rx] [span-loss-baseline-rx] [span-loss-baseline-tx] [target-power-setting] [target-power-adjust-cband]
[target-power-adjust-lband] [laser-safety-mode] [loading-policy]
```

#### Examples

This example shows how to set OTS OSC compatibility to osc-7100 and, for DCN interworking, set the enable DCN interworking to true:

```
set ots-1-1-dwdm-line osc-compatibility osc-7100
set ots-1-1-dwdm-line enable-dcn-interworking true
```
