## 6.313. stm

#### Command Description

This command is used to set or show STM attributes.

#### Command Syntax

```
set stm-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [tx-mapping-mode <value>] [expected-mapping-mode <value>]
[tti-style <value>] [tim-monitor <value>] [tx-tti <value>] [expected-tti <value>] [loopback <value>] [loopback-mode <value>] [test-signal-type
<value>] [test-signal-direction <value>] [test-signal-monitoring <value>]
show stm-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state]
[oper-state] [avail-state] [managed-by] [alarm-report-control] [stm-type] [speed] [tx-mapping-mode] [expected-mapping-mode] [service-mode]
[service-mode-qualifier] [tti-style] [tim-monitor] [tx-tti] [rx-tti] [rx-tti-hex] [expected-tti] [loopback] [loopback-mode] [test-signal-type]
[test-signal-direction] [test-signal-monitoring] [circuit-id]
```

#### Command Usage Details

**Table 727: stm Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 728: stm Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| name | The name of the Synchronous Transport Module N, e.g. N=16, 64. Reference [ITU-T G.691]. | string | n/a | add, set, show, delete |
| label | A user configurable label. | string | n/a | add, set, show |
| admin-state | Administrative state of the object. | Lock, Unlock, Maintenance | Unlock | add, set, show |
| alarm-report-control | Controls the reporting of alarms for this particular object.<br>• allowed - Alarm reporting is allowed.<br>• inhibited - Alarm reporting is inhibited. | • allowed<br>• inhibited | allowed | add, set, show |
| stm-type | The type of SDH signal (STM-N). | STM-16, STM-64 | n/a | show |
| speed | The speed of client interface | speed | n/a | show |
| tx-mapping-mode | The tx mapping mode of client port. The possible values are dependent on the HW and configuration. | mapping-mode | n/a | add, set, show |
| expected-mapping-mode | The expected mapping mode of client port. The possible values are dependent on the HW and configuration. | true, false | false | add, set, show |
| tti-style | The configured mode of the TTI for this OTU/ODU client. | ITU-T-G709, proprietary | ITU-T-G709 | add, set, show |
| tim-monitor | The enable switching of tim defect monitor mode | enabled,disabled | disabled | add, set, show |
| tx-tti | Transmit TTI - Sent by this facility to the far-end remote facility. | tti-64 | tti-64 | add, set, show |
| expected-tti | Expected TTI - The TTI this facility expects to receive from the far-end remote facility. | tti-64 | n\/a | add, set, show |
| loopback |  |  |  | add, set, show |
| loopback-mode | Indicates loopback action for facility or terminal. | none, facility, terminal | none | add, set, show |
| test-signal-type | The type of test pattern that is injected. | none, PRBS31Q, PRBS13Q, scrambled-idles, PRBS9, PRBS31 | none | add, set, show |
| test-signal-direction | The direction of the test signal. | Ingress | Ingress | add, set, show |

| service-mode | A custom type for legacy Nokia SM attribute. | none, network-wrapper, adaptation, switching, transport | n/a | show |
| service-mode-qualifier | A custom type for legacy Nokia SMQ attribute; string here represents the upper-layer protocol (e.g. ODUC4i). | none, mux-demux, nofec, string 0..32 | n/a | show |
| circuit-id | The system configured circuit ID | string | n/a | show |

#### Examples

This example shows how to set tx-mapping-mode attribute from an STM object in a 1830 GX G40 node:

```
set stm-1-5-T9.2 tx-mapping-mode BMP
```
