## 6.209. oms

#### Command Description

These commands are used to set or show the Optical Multiplex Section (OMS) facility attributes.

#### Command Syntax

```
set oms-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [monitoring-mode <value>] [configured-spectrum
<value>] [target-output-power <value>] [grid-mode <value>] [attenuation-control-mode-rx <value>] [attenuation-control-mode-tx <value>]
[control-speed-factor <value>] [min-wss-bias-tx <value>]
show oms-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [monitoring-mode] [wss-less] [assigned-degree] [power-actual-rx] [power-actual-tx]
[bands-supported-link] [band-allowed] [band-actual] [band-target] [configured-spectrum] [lower-frequency] [upper-frequency] [target-output-power]
[grid-mode] [grid-mode-support] [attenuation-control-mode-rx] [attenuation-control-mode-tx] [control-speed-factor] [attenuation-control-state-rx]
[attenuation-control-state-tx] [min-wss-bias-tx] [monitoring-state]
```

#### Examples

This example shows how to view the attenuation-control-mode-tx of an OMS in 1830 GX G30 node:

```
show oms-1-1-dwdm-line attenuation-control-mode-tx
```

This example shows how to set the set the OMS attenuation-control-mode-tx to manual in a 1830 GX G30 node:

```
set oms-1-1-dwdm-line attenuation-control-mode-tx manual
```
