## 6.109. file-operation

#### Command Description

This command is used to perform basic file and directory operations..

#### Command Syntax

```
file-operation [[operation=]<value>] [new-file-path=]<value> [file-path=]<value>
```

#### Command Usage Details

**Table 304: file-operation Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode |

#### Command Parameters

**Table 305: file-operation Command Parameters**

| Parameter | Description | Values | Default |
| --- | --- | --- | --- |
| operation | File operations to perform | rename, delete, view | n/a |
| new-file-path | A new path to the file | string | n/a |
| file-path | The path to the file | string | n/a |
