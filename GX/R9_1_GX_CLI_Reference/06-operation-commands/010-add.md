## 6.10. add

#### Command Description

The `add` command is used to create a new managed entity. This command is used to create a new managed entity in the system database. Depending on the managed entity type, the entity id will be different. Some entities have mandatory attributes that need to be provided upon creation. If a mandatory attribute is not provided in the command itself, the CLI will automatically ask for it. It is also possible to initialize non-mandatory attributes by providing attribute-value pairs. Using the -m flag performs a merge, which in fact is a best effort add. If the target entity doesn't exist, it will be created; if it exists, it will be updated with any attributes present on the 'add' command. Using the -v flag performs a command validation only (the target entity is not created). If valid, the command replies with 'OK'. Otherwise the command will fail.

**Tip:** Use `add <tab>` to visualize all entity types that are creatable at that time.

**Tip:** Entities managed by the system cannot be created using the `add` command.

#### Command Syntax

```
add -h
add [-v|-m|-f] <entity id> [(<attribute> <value>) ...]
```

#### Command Parameters

**Table 88: add Command Flags**

| Parameter | Description |
| --- | --- |
| -h | Displays help for this command. |
| -m | Merge configuration (will not fail if entity already exists). If valid, the command replies with 'OK'. Otherwise the command will fail. |
| -v | Validates the command. |
| -f | Forces the command without confirmation. |

**Table 89: add Command Parameters**

| Parameter | Description |
| --- | --- |
| entity id | Instance ID of the entity to be created. |
| attribute | Name of the attribute to be provided. |
| value | Value of the attribute to be initialized. |
