## 6.215. osc

#### Command Description

These commands are used to set or show the Optical Supervisory Channel (OSC) facility attributes.

#### Command Syntax

```
set osc-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [l0-comm-interface-type <value>] [osc-control <value>]
[target-output-power <value>] [tx-power-adjustment] [voa-attenuation-target-rx <value>][lof-soak-timer <value>]
show osc-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [monitoring-mode] [oscc-support] [osc-mode] [l0-comm-interface-type] [osc-wavelength]
[osc-control] [target-output-power] [tx-power-adjustment] [voa-attenuation-target-rx] [voa-attenuation-actual-rx] [lof-soak-timer]
[power-actual-rx] [power-actual-tx]
```

#### Examples

The following example shows how to view all the osc entities and related parameters:

```
show osc
```

The following example shows how to view a specific osc entity and related parameters:

```
show osc-1-3-dwdm-line
```
