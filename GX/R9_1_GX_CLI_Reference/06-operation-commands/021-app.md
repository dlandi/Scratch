## 6.21. app

#### Command Description

The `clear app` command, clears third party apps.

#### Command Syntax

```
clear [-f] app [app-name=]<value>
```

#### Command Usage Details

**Table 112: app Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 113: app Command Flags**

| Parameter | Description |
| --- | --- |
| -f | Forces the command without confirmation. |

**Table 114: app Command Parameters**

| Parameter | Description |
| --- | --- |
| app-name | Third party app name. |
