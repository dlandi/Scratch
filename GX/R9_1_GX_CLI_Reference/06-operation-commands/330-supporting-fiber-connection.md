## 6.330. supporting-fiber-connection

#### Command Description

The commands described in this section are used to show the list of fiber connections.

#### Command Syntax

```
show supporting-fiber-connection-<name> [fiber-connection-list]
```

#### Command Usage Details

**Table 760: supporting-fiber-connection Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

**Table 761: supporting-fiber-connection Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| name | Name of the entity. | String (length 0..64) | n/a | show |
| fiber-connection-list | Supported fiber connection path. | instance-identifier | n/a | show |
