## 6.207. odu

#### Command Description

These commands are used to add, set, show an ODU facility. ODU4i (100G) or ODUflexi (400G) facilities represent low order ODUs that XCONs are mapped into. Use the delete command to delete the ODU from the configuration.

**Note:** When a CHM6 has a OTU configured on it, use the `show odu` command to determine if the ODU exists. The high order ODU is automatically created when an SCH is created.

```
<value>] [time-slots <value>] [opucn-time-slots <value>] [expected-trib-port-number <value>] [expected-time-slots <value>] [tx-payload-type
<value>] [expected-payload-type <value>] [delay-measurement-enable <value>] [msim-config <value>] [client-signal-type <value>]

[avail-state] [managed-by] [alarm-report-control] [parent-odu] [odu-type] [rate] [odu-name] [class] [service-mode] [service-mode-qualifier]

[msim-config] [client-signal-type] [used-resources]

```

#### Examples

The following examples show how to add an ODU in 1830 GX G30:

```
add ODU-1-2-1-ODU4-1 opucn-time-slots 1.1..1.20 odu-type ODU4 parent-odu 1-2-1-ODUC4 trib-port-number 1
add ODU-1-2-2-ODUFlex-1 opucn-time-slots 1.1..4.20 odu-type ODUflex parent-odu 1-2-2-ODUC4 trib-port-number 1
```

The following example show how to add ODUflex under UTM2 parent ODU2 in 1830 GX G30:

```
add odu-1-1-8-ODUflex-2 parent-odu 1-1-8-ODU2 odu-type ODUflex time-slots 1..4 trib-port-number 1 client-signal-type FC4G
```

The following examples show how to add ODU4i with contiguous timeslots in 1830 GX G40:

```
add odu-1-1 odu-type ODU4i parent-odu '1-7-L1-1-ODUCni' time-slots 1..80
add odu-1-2 odu-type ODU4i parent-odu '1-7-L1-1-ODUCni' time-slots 81..160
```

The following examples show how to add an ODU49 with non-contiguous timeslots in 1830 GX G40:

```
add odu-1-1 odu-type ODU4i parent-odu '1-7-L1-1-ODUCni' time-slots 1..20,561..580,961..1000
add odu-1-1 odu-type ODU4i parent-odu '1-7-L1-1-ODUCni' time-slots 21..40,581..600,1001..1040
```

The following examples show how to add an ODUFLEXi with continuous timeslots in 1830 GX G40:

```
add odu-1-1 odu-type ODUFlexi parent-odu '1-5-L1-1-ODUCni' time-slots 1..320
add odu-1-2 odu-type ODUFlexi parent-odu '1-5-L1-1-ODUCni' time-slots 321..640
```

The following examples show how to edit an ODU4 in 1830 GX G40:

```
set odu-1-5-T3-1-OdU4-1 admin-state lock loopback terminal admin-state locked
```

The following examples displays the used-resources in DSP for ODU facility:

```
show odu-1-4-T2 used-resources
  odu-1-4-T2
  used-resources          8,9,10,11
```

The following examples show how to add an ODUFLEXi with non-continuous timeslots in 1830 GX G40:

```
add odu-1-1 odu-type ODUFlexi parent-odu '1-7-L1-1-ODUCni' time-slots 1..100,401..500,801..900,1201..1220
add odu-1-2 odu-type ODUFlexi parent-odu '1-7-L1-1-ODUCni' time-slots 101..200,501..600,901..1000,1221..1240
```
