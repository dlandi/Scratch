## 6.193. nmc

#### Command Description

These commands are used to add, delete the Network Media Channel (NMC), and set or show the NMC facility attributes.

#### Command Syntax

```
add nmc-<name> parent-facility <value> center-frequency <value> [label <value>] [admin-state <value>] [alarm-report-control <value>]
[width <value>] [input-power-min <value>] [input-power-max <value>] [input-power-typical <value>] [input-power-min-offset <value>]
[input-attenuation-target <value>] [output-attenuation-offset <value>] [input-attenuation-offset <value>] [output-attenuation-target <value>]
[ase-insertion-enable <value>] [ase-insertion-soak-timer <value>] [ase-insertion-control <value>] [ase-insertion-delta <value>] [acrd-reference
<value>] [auto-delete <value>]
set nmc-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [input-power-min <value>] [input-power-max <value>]
[input-power-typical <value>] [input-power-min-offset <value>] [input-attenuation-target <value>] [output-attenuation-offset <value>]
[input-attenuation-offset <value>] [output-attenuation-target <value>] [ase-insertion-enable <value>] [ase-insertion-soak-timer <value>]
[ase-insertion-control <value>] [ase-insertion-delta <value>] [acrd-reference <value>] [auto-delete <value>]
show nmc-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state]
[oper-state] [avail-state] [managed-by] [alarm-report-control] [parent-facility] [och-connection] [monitoring-state] [center-frequency]
[width] [input-power-min] [input-power-max] [input-power-typical] [input-power-min-offset] [input-psd-min] [input-psd-max]
[input-psd-typical] [input-attenuation-actual] [input-attenuation-target] [output-attenuation-offset] [input-attenuation-offset]
[input-attenuation-compensation-actual] [output-attenuation-actual] [output-attenuation-target] [power-actual-rx] [power-actual-tx]
[ase-power-actual-tx] [ase-activation-state] [target-power-ase] [attenuation-actual-ase] [psd-actual-rx] [psd-actual-tx]
[ase-insertion-enable] [ase-insertion-soak-timer] [ase-insertion-control] [ase-insertion-delta] [acrd-reference] [loopback-state]
[output-attenuation-compensation-actual] [ase-attenuation-compensation-actual] [auto-delete]
delete nmc-<name>
```

#### Examples

This example shows how to add an NMC:

```
add nmc-cdc-1-4_192800000-34000 center-frequency 192800000 width 34000 parent-facility oms-1-4-ad1
```
