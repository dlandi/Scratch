## 6.306. ssh

#### Command Description

These commands are used to set or show attributes of secure shell access. This object is managed by the system and can not be manually deleted.

#### Command Syntax

```
set ssh [enabled <value>] [port <value>] [pre-login-message <value>] [post-login-message <value>]
show ssh [enabled] [port] [pre-login-message] [post-login-message]
```

#### Command Usage Details

**Table 712: ssh Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 713: ssh Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| enabled | Enables direct access to shell via ssh. | true, false | false | set, show |
| port | Port listening for ssh login that goes directly to shell. | Number (range: 1..65535) | 8022 | set, show |
| pre-login-message | Welcome message displayed before user login. | String (length 0..1440) | n/a | set, show |
| post-login-message | Welcome message displayed after user login. | String (length 0..1440) | ******************************** ********** Warning ******************************** ********** This system is restricted to authorized users for business purposes. Unauthorized access is a violation of the law. This service may be monitored for administrative and security reasons. By proceeding, you consent to this monitoring. ******************************** | set, show |

#### Examples

This example shows how to view ssh:

```
show ssh
```

This example shows how to set the ssh pre-log-in message:

```
set ssh pre-login-message "This system is restricted to authorized users only"
```
