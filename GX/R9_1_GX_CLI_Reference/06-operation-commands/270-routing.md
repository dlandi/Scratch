## 6.270. routing

#### Command Description

This command is used to show routing information.

#### Command Syntax

```
show routing
```

#### Command Usage Details

**Table 633: routing Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

This example shows how to view the routing information:

```
show routing
```
