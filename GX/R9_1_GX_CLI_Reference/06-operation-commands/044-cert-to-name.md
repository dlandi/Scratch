## 6.44. cert-to-name

#### Command Description

This command defines a prioritized set of rules used to map an X.509 client certificate to a specific user identity. Each rule either extracts a username from a certificate field or maps it directly based on defined criteria or a specific issuer within the certificate's trust chain.

#### Command Syntax

```
add cert-to-name-<id> map-type <value> field <value> mapped-user-name <value> criteria <value> [priority <value>] [issuer <value>] [enabled
<value>] [label <value>]
delete cert-to-name-<id>
set cert-to-name-<id> [priority <value>] [field <value>] [mapped-user-name <value>] [criteria <value>] [issuer <value>] [enabled <value>] [label
<value>]
show cert-to-name-<id> [priority] [map-type] [field] [mapped-user-name] [criteria] [issuer] [enabled] [label]
```

**Table 161: cert-to-name Command Usage**

| Section | Description |

#### Command Parameters

**Table 162: cert-to-name Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| id | Indicates the unique identifier for the entry. | n/a | n/a | add, set, delete, show |
| map-type | Specifies whether to map the certificate to an explicit username or extract the identity from a designated certificate field. | • extract<br>• map | n/a | add, set, show |
| field | Applicable only when Map-Type selected is "extract". Specifies the certificate attribute used to determine the user identity. | • common-name<br>• san-any<br>• san-dns-name<br>• san-ip-address<br>• san-rfc822-name<br>• san-upn<br>• san-uri | n/a | add, set, show |
| mapped-user-name | Required only if Map-Type is "map". Defines the local or remote user identity associated with the presented X.509 client certificate. | n/a | n/a | add, set, show |
| criteria | Defines the specific attributes and conditions required for the rule to be invoked. | n/a | n/a | add, set, show |
| priority | Specifies a priority value for each entry. | The value range is 1 to 255. | n/a | add, set, show |
| issuer | Specifies additional restriction that filters certificates generated by a specific issuer. | any | n/a | add, set, show |
| enabled | Specifies whether certificate-to-name mapping is enabled. | • True<br>• False | True | add, set, show |
| label | Specifies the user label. | n/a | n/a | add, set, show |

#### Examples

- The following example shows how to extract usernames from certificate fields:

```
add cert-to-name-rule_name map-type extract field san-dns-name
```

- The following example shows how to delete an entire rule:

```
delete cert-to-name-rule_name
```
