## 6.189. network-xconnect

#### Command Description

This command is used to show the list of services of multiple user cross connections commissioned in this NE.

#### Command Syntax

```
show network-xconnect
```

#### Command Usage Details

**Table 466: network-xconnect Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

The following example shows how to view the list of user cross connections commissioned in this NE:

```
show networking-xconnect
```
