## 6.187. ne-function

#### Command Description

This command is used to show the Network Element (NE) function.

#### Command Syntax

```
show ne-function
```

#### Command Usage Details

**Table 463: ne-function Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |

#### Command Parameters

None.

#### Examples

The following example shows how to view the NE generic functions from a 1830 GX G30 node:

```
show ne-function
  direction-1
  direction-2
  direction-3
  direction-4
  direction-5
  direction-6
  direction-7
  direction-8
  amplifier-raman-1-7
  amplifier-1-1-A
  amplifier-1-1-B
  amplifier-1-3.1-drop
  amplifier-1-5-A
  amplifier-1-5-B
  amplifier-2-1-A
  amplifier-2-1-B
  amplifier-2-3-A
  amplifier-2-3-B
  ne-function
```
