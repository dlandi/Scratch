## 6.236. pm

#### Command Description

**clear pm** The `clear pm` command, removes or resets PM data. This command clears the selected PM data. The \<data-type\> is mandatory and may be real-time, current or history. All other filters are optional, and can be used together (cleared data needs to match all filters).

**Note:** The clear PM command clears all PM data for the given data-type unless additional parameters are provided, in which case the target of the clearing is narrowed.

**show pm** The `show pm` displays the PM statistics data measured by the system. The PM (Performance Management) Data is composed of:

- real-time PM data, which is continuously updated and has latest values available
- binned PM data, which is organized into time-window based records called 'bins'; each bin represents a history record for a specific timestamp. Bin 0 represents the current data, while bins 1 to n represent the history data.

The NE stores PM data for multiple time granularities (15min and 24h), and as such the time between the bins will be different depending on the PM type. The output of this command will depend on the type of data to display:

- real-time and current data will be displayed in a per-resource table;
- history data will be displayed with all bins representing rows in a table. The mapping between bin number and timestamp is also presented;
- single generic table, if flag -t is provided.

It is possible to filter the data to be displayed by using both \<command flag\> and \<pm-filter\> parameters. It is also possible to use -s and -e, or -sbin and -ebin together in order to define a timestamp based filter. Additionally, it is possible to filter the data based on content filters. These include type of PM bin (pm-15min, pm-24h), type of PM parameter/counter, managed entity that contains the PM data, etc.

<!-- page 935 -->

**Tip:** Use `show pm <tab>` for a complete list of filters that are supported.

**Tip:** Use `show pm <command flag> | display csv` to output CSV data, which is importable to a spreadsheet (e.g. Excel). Also available are 'display xml' and 'display json'.

#### Command Syntax

```
clear [-f] [-i=] pm [[direction=]<value>] [[resource=]<value>] [[resource-type=]<value>] [[period=]<value>] [data-type=]<value>
[[location=]<value>] [[AID=]<value>]
show pm [<command flag>] [<pm-filter> ...]
```

#### Command Parameters

**Table 564: pm Command Flags**

| Parameter | Description |
| --- | --- |
| -t | Shows PM data in standard table format. |
| -f | Forces the command without confirmation. |
| -i=&lt;chassis-name&gt; | Shows the PM data for the chassis with chassis-name=&lt;chassis-name&gt;. i Note: The chassis flag (-i) can only be provided once per command. Chassis flag representing a non-existing or even invalid chassis id will fail. Chassis flag representing an existing chassis, but targeting an object that does not exist in that chassis, will also fail. |
| -n=&lt;number-of-records&gt; | Maximum number of records that will be retrieved, per chassis. The default is 1000 records. |
| -s=&lt;skip-records&gt; | Skips the first entries of number of records. Allows a user to specify a number of records that will be skipped, so that the total data can be fetched in multiple requests. |
| -st=&lt;timestamp&gt; | Start time of the PM record entry; format example: 2021-02-01T10:00:00+01:00. |
| -et=&lt;timestamp&gt; | End time of the PM record entry; same format as for -st. |
| -sbin=&lt;number&gt; | First bin to display; by default, bin 0 (current data) is the first bin. |
| -ebin=&lt;number&gt; | Last bin to display; by default, all available bins are displayed. |

#### Examples

This example shows how to reset all real-time data:

```
clear pm real-time
```

<!-- page 938 -->

This example shows how to clear all history data for resource-type PEM:

```
clear pm history PEM
```

This example shows how to clear 15min PM data for card-17 entity:

```
clear pm card-1-7 history pm-15min
```

This example shows how to view all system PM data:

```
show pm
```
