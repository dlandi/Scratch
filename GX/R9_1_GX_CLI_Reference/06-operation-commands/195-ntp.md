## 6.195. ntp

#### Command Description

These commands are used to configure and show the Network Time Protocol. This object is managed by the system and can not be manually added/deleted.

#### Command Syntax

```
set ntp [ntp-enabled <value>] [ntp-auth-enabled <value>] [assignment-method <value>]
show ntp [ntp-enabled] [ntp-auth-enabled] [ntp-active-server] [assignment-method]
```

#### Command Usage Details

**Table 476: ntp Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 477: ntp Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| ntp-enabled | Whether ntp is enabled. | true, false | true | set, show |
| ntp-auth-enabled | Whether NTP authentication is enabled. | true, false | false | set, show |
| ntp-active-server | Currently active NTP server. | string (NTP server) | n/a | set, show |
| assignment-method | The system contains manual and dhcp configured values. System can use those configurations/values defined by assignment-method attributes | manual, dhcp, both | both | set, show |

#### Examples

This example shows how to enable ntp:

```
set ntp ntp-enabled true
```
