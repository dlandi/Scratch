# 6. Operation Commands

This section provides information and examples on how the operational commands can be used while operating the 1830 GX G30/1830 GX G40. It also provides the list of objects/entities and the available operational commands for each object/entity.

**Note:** Unless stated otherwise, always assume the root command prompt [ne] for all the examples in this section.
