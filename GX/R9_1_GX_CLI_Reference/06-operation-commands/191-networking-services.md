## 6.191. networking-services

#### Command Description

This command is used to show the list of network services.

#### Command Syntax

```
show networking-services
```

#### Command Usage Details

**Table 469: networking-services Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

The following example shows how to view the list of network services:

```
show networking-services
```
