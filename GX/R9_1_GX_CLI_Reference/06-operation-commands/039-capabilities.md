## 6.39. capabilities

#### Command Description

This command is used to retrieve information about a cards capabilities.

#### Command Syntax

```
show capabilities-<name>
```

#### Command Usage Details

**Table 150: capabilities Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 151: capabilities Command Parameters**

| Parameter | Description | Values | Default |
| --- | --- | --- | --- |
| name | the name of the card | string | n/a |
