## 6.3. access-control-list

#### Command Description

This command is used to show access control list.

#### Command Syntax

```
show access-control-list
```

#### Command Usage Details

**Table 65: access-control-list Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Examples

This example shows how to view the access control list:

```
show access-control-list
```
