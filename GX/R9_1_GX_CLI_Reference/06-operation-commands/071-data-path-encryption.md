## 6.71. data-path-encryption

#### Command Description

This command is used to show datapath encryption attributes.

#### Command Syntax

```
show data-path-encryption
```

#### Command Usage Details

**Table 221: data-path-encryption Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

This example shows how to display data path encryption:

```
show data-path-encryption
```
