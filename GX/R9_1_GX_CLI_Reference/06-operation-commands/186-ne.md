## 6.186. ne

#### Command Description

These commands are used to set/show network element attributes. This object is managed by the system and cannot be manually deleted.

#### Command Syntax

```
set ne [ne-name <value>] [label <value>] [node-type <value>] [l0-mode-op <value>] [ne-site <value>] [ne-location <value>] [ne-sub-location
<value>] [clli <value>] [node-controller-chassis-name <value>] [altitude <value>] [latitude <value>] [longitude <value>] [contact <value>]
[alarm-report-control <value>]
show ne [ne-id] [ne-name] [label] [ne-type] [node-type] [l0-mode-op] [ne-vendor] [ne-site] [ne-location] [ne-sub-location] [clli]
[node-controller-chassis-name] [altitude] [latitude] [longitude] [equipment-discovery-ready] [alarm-report-ready] [contact] [recover-mode]
[original-recover-mode-reason] [recover-mode-reason] [oper-state] [avail-state] [alarm-report-control]
```

```
set ne label remoteoffice
```
