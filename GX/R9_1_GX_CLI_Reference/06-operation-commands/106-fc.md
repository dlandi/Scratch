## 6.106. fc

#### Command Description

The commands described in this section are used to set or show the `fc` attributes.

#### Command Syntax

```
set fc-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [tx-mapping-mode <value>] [expected-mapping-mode <value>]
[loopback <value>] [loopback-mode <value>] [test-signal-type <value>] [test-signal-direction <value>] [test-signal-monitoring <value>] [tts
<value>] [laser-toggling-for-tts <value>]
show fc-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state]
[oper-state] [avail-state] [managed-by] [alarm-report-control] [fc-type] [service-mode] [service-mode-qualifier] [speed] [tx-mapping-mode]
[expected-mapping-mode] [loopback] [loopback-mode] [test-signal-type] [test-signal-direction] [test-signal-monitoring] [circuit-id] [tts]
[laser-toggling-for-tts]
```
