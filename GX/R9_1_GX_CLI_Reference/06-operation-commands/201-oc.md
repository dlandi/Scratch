## 6.201. oc

#### Command Description

This command is used to enable, edit or show the attributes of an optical carrier. Use the delete command to remove an oc from the configuration.

#### Command Syntax

```
set oc-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [tx-mapping-mode <value>] [expected-mapping-mode <value>]
[tti-style <value>] [tim-monitor <value>] [tx-tti <value>] [expected-tti <value>] [loopback <value>] [loopback-mode <value>] [test-signal-type
<value>] [test-signal-direction <value>] [test-signal-monitoring <value>]
show oc-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state]
[oper-state] [avail-state] [managed-by] [alarm-report-control] [oc-type] [speed] [tx-mapping-mode] [expected-mapping-mode] [service-mode]
[service-mode-qualifier] [tti-style] [tim-monitor] [tx-tti] [rx-tti] [rx-tti-hex] [expected-tti] [loopback] [loopback-mode] [test-signal-type]
[test-signal-direction] [test-signal-monitoring] [circuit-id]
```

#### Command Usage Details

**Table 488: oc Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

**Table 489: oc Command Parameters**
