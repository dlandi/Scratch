## 6.267. rib

#### Command Description

This command is used to show RIB entries. Each entry represents a RIB identified by the 'name' key. All routes in a RIB belong to the same address family. For each routing instance, the system will provide one system-controlled default RIB for each supported address family.

#### Command Syntax

```
show rib-<rib-name> [vrf] [address-family]
```

#### Command Usage Details

**Table 627: rib Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 628: rib Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| rib-name | The name of the RIB. | String (length 1..64) | n/a | show |
| vrf | VRF to which this RIB is bound. | leafref (path "../../vrf/name") | n/a | show |
| address-family | Address family. | ipv4-unicast ipv6-unicast | n/a | show |

#### Examples

This example shows how to view a RIB identified by the 'IPv4' key:

```
show rib-IPv4
```
