## 6.331. supporting-interface

#### Command Description

This command is used to show supporting interface information.

#### Command Syntax

```
show supporting-interface-<name>/<interface>
```

#### Command Usage Details

**Table 762: supporting-interface Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 763: supporting-interface Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| name | The name of the interface. | string | n/a | show |
| interface | A reference to the IPv4/IPv6 interface. | path | ../../../../../networking/interface/if-name | show |
