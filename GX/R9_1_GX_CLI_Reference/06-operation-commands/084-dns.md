## 6.84. dns

#### Command Description

These commands are used to edit or show the domain name service instance.

#### Command Syntax

```
set dns [assignment-method <value>] [enabled <value>] [search <value>]
show dns [assignment-method] [enabled] [search]
```

#### Command Usage Details

**Table 251: dns Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 252: dns Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| assignment-method | Indicates whether the system contains manual and/or dhcp configured values. The assignment method can be both manual and dhcp. | manual, dhcp, both | both | set, show |
| enabled | Flag indicating if DNS is enabled. | true, false | true | set, show |
| search | DNS-search-suffix name. It must contain at least a single dot. To clear the value, set the string to an empty string. | String (length 0..64) | n/a | set, show |

#### Examples

This example shows how to enable DNS:

```
set DNS enabled true
```

This example shows how to view DNS settings:

```
show DNS
```
