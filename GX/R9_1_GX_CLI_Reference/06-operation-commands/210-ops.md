## 6.210. ops

#### Command Description

These commands are used to set or show the Optical Physical Section (OPS) facility attributes.

#### Command Syntax

```
set ops-<name> [label <value>] [admin-state <value>] [alarm-report-control <value>] [input-psd-profile <value>] [role <value>] [port-expansion
<value>]
show ops-<name> [supporting-card] [supporting-port] [supporting-facilities] [supported-facilities] [AID] [label] [admin-state] [oper-state]
[avail-state] [managed-by] [alarm-report-control] [input-psd-profile] [role] [supported-roles] [port-expansion]
```

#### Command Usage Details

**Table 506: ops Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Examples

This example shows how to set the OPS role of the tributary port of CDC8D6, connected to the CHM1R port, to tributary:

```
set ops-1-6-ad1 role tributary
```
