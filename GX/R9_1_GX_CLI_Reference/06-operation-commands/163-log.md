## 6.163. log

#### Command Description

**show log** This command is used to retrieve log files . If no \<logname\> is provided, the list of available logs is displayed. Otherwise, all the log entries of \<logname\> are displayed. It is possible to display only the last x log entries by using the -n=x option. By default, log entries are shown in CSV format where each column is named in the header (same as the actual file content). Columns differ for each log type. An alternative table display can be used with the -t option; in this mode, the columns will be aligned, making it easier to read, but potentially making the whole table too wide. When this happens, it is possible to remove unwanted columns by referencing them after the \<logname\> with the exclude=\<column\> parameter. Post process the 'show' results by using piped commands:

- show -r \| include card
- show log security \| exclude john \| include NETCONF

**Note:** Use auto-complete (\<tab\>) to get a list of columns that can be removed from the display.

**clear log** This command is used to remove the content of an existing log-file. The file itself will still exist and continue logging new messages. Use 'show log' to visualize currently available log files.

**Note:** Due to system restrictions, the security log may not be cleared.

#### Command Syntax

```
clear [-f] log [log-file-name=]<value>
show [-n=<number>] [-t] log [<logname> [exclude=<exclude-column> ...]]
```

#### Examples

This example shows how to display the list of available logs:

```
show log
```

The following output is displayed:

```
configuration
apps
kernel
user
ztp
security
linecards
messages
event
cli-command
```

This example shows how to display the user log in table mode:

```
show log user -t
```

This example shows how to display the last 5 entries in the event log :

```
show -n=5 log event
```
