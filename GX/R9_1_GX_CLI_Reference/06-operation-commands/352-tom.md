## 6.352. tom

#### Command Description

These commands are used to add, set, show or delete a TOM (Tunable/non-tunable Optical Module) pluggable.

**Note:** The Tributary Port termination point is auto-created when the TOM is created. It is automatically deleted when the TOM is deleted.

#### Command Syntax

```
add tom-<card-name>-<port-name> required-type <value> [required-subtype <value>] [phy-mode <value>] [power-class-override <value>] [alias-name
<value>] [admin-state <value>] [alarm-report-control <value>] [label <value>] [enable-serdes <value>] [power-mode <value>]
set tom-<card-name>-<port-name> [required-subtype <value>] [phy-mode <value>] [power-class-override <value>] [alias-name <value>] [admin-state
<value>] [alarm-report-control <value>] [label <value>] [enable-serdes <value>] [power-mode <value>]
show tom-<card-name>-<port-name> [required-type] [required-subtype] [phy-mode] [supported-phy-modes] [power-class-override] [upgrade-status]
[alias-name] [AID] [admin-state] [oper-state] [avail-state] [alarm-report-control] [label] [enable-serdes <value>] [power-mode <value>]
delete tom-<card-name>-<port-name>
```

#### Examples

This example shows how to add a TOM in a 1830 GX G40 node:

```
add tom-1-4-T1 required-type QSFPDD
```
