## 6.347. templates

#### Command Description

This command is used to show the configuration that defines the data model for system templates.

#### Command Syntax

```
show templates
```

#### Command Usage Details

**Table 797: templates command usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

This example shows how to view templates information:

```
show templates
```
