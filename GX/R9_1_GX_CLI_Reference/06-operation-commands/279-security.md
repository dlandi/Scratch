## 6.279. security

#### Command Description

The command described in this section is used to show the top level security container.

#### Command Syntax

```
show security
```

#### Command Usage Details

**Table 651: security Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Examples

This example shows how to view all the system's security containers:

```
show security
```
