## 6.28. bert

#### Command Description

The commands described in this section are used to start/ stop/get/delete the attributes associated with the Bit Error Rate Test - BERT operations.

#### Command Syntax

```
bert [operation=]<value> [[test-id=]<value>] [[resource=]<value>] [[resource-type=]<value>] [[AID=]<value>] [[test-signal-type=]<value>]
[[test-signal-direction=]<value>] [[test-signal-monitoring-type=]<value>] [[test-signal-monitoring-direction=]<value>] [[test-duration=]<value>]
bert start test-id=TestX resource=ethernet-1-6-T1 test-signal-type=scrambled-idles test-signal-monitoring-type=scrambled-idles
test-signal-direction=ingress test-signal-monitoring-direction=egress test-duration=10
bert stop test-id=TestX
bert get
bert get test-id=TestX
bert delete test-id=TestX
```

#### Examples

The following example command is used to retrieve the record of a particular test.

```
bert get test-id=TestX
```

The following example command is used to retrieve all test records associated with a resource:

```
bert get resource=ethernet-1-6-T1
```

The following example command is used to retrieve all test records associated with an AID:

```
bert get AID=1-6-T1
```

The following example command is used to start the BERT. Multiple simultaneous BERT tests can be run on a facility, if each desired test individually fulfills the pre-conditions:

```
bert start test-id=TestX resource=ethernet-1-6-T1 test-signal-type=scrambled-idles test-signal-monitoring-type=scrambled-idles
 test-signal-direction=ingress test-signal-monitoring-direction=ingress test-duration=10
```

The following example command is used to stop or abort an in-progress BERT:

```
bert stop test-id=TestX
```

**Note:** The `test-id` attribute is mandatory for the bert `stop`command.

The following example command is used to delete a test record of a particular test:

<!-- page 235 -->

```
bert delete test-id=TestX
```

The following example command is used to delete all test records associated with a particular resource:

```
bert delete resource=card-1-6
```
