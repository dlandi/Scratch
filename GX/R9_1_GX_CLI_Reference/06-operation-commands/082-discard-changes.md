## 6.82. discard-changes

#### Command Description

This command will discard all candidate datastore content and CLI return to operational mode.

#### Command Syntax

```
discard-changes
```

#### Command Usage Details

**Table 248: discard-changes Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Candidate Configuration mode |

#### Command Parameters

None.

#### Examples

This example shows how to discard changes and return to operational mode:

```
discard-changes
```
