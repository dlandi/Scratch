## 6.272. run

#### Command Description

This command is used to execute a previously configured/defined/scheduled task or a script.

#### Command Syntax

```
run task [-h]
run task [[task-name=]<value>]
run script [-q] [-y] [-e=<value>] [-r] [[script-name=]<value>] [[arguments=]<value>]
```

#### Command Usage Details

**Table 636: run Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational Mode, Candidate Configuration Mode |
| Pre-condition | The task or the script to be called must be defined. |

#### Command Parameters

**Table 637: run Command Flags**

| Parameter | Description |
| --- | --- |
| -h | Displays help for this command. |
| -q | Execute CLI script in quiet mode. Only command output is shown to user; otherwise both command being executed and command output is shown. |
| -r | Replace operation. If present executes script as a declarative config script, effectively replacing system configuration with content of the script. |
| -e | Configure error option (-e flag in CLI) , with options:<br>• continue: continue on error (default)<br>• stop: stop on error<br>• rollback: rollback on error |

**Table 638: run Command Parameters**

| Parameter | Description | Values | Default |
| --- | --- | --- | --- |
| task-name | The task name to be executed. | leafref (path "/ioa-ne:ne/ioa-ne:system/ ioa-ne:scheduled-tasks/ioa-ne:task/ioa-ne:name") | n/a |
| script-name | The script name is a relative path to the script directory. | string | n/a |
| arguments | Optional arguments to the script. | string | n/a |

#### Examples

This example shows how to execute the previous configured scheduled task 'collect-diag':

```
run task collect-diag
```

This example shows how to execute the script 'config.cli' in quiet mode with stop on error option:

```
run script config.cli -e=stop -q
```
