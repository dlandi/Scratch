## 6.42. cdp

#### Command Description

This command is used to manage manually configured CRL Distribution Points (CDPs). Each CDP will support download and auto-refreshing of a specified CRL.

#### Command Syntax

```
add cdp-<name> url <value> [enabled <value>] [refresh-interval <value>]
set cdp-<name> [enabled <value>] [refresh-interval <value>]
show cdp-<name> [url] [enabled] [refresh-interval] [next-update-time] [last-update-time] [last-update-result]
delete cdp
delete cdp-<name>
show cdps
```

#### Command Usage Details

**Table 156: cdp command usage**

| Section | Description |
| --- | --- |
| User Access Privilege Level | System Administrator |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 157: cdp command parameters**

| Parameter | Description | Valid Range | Default | Used in |
| --- | --- | --- | --- | --- |
| name | A unique object identifier for the CDP. | string | n/a | add, set, delete, show |
| url | HTTP URL of CRL. The CRL will be fetched from this location. | The format is 'http:// &lt;host&gt;[:&lt;port&gt;]/&lt;path to crl file&gt;' _ _ _ where - '&lt;host&gt;' may be IPv4/ v6 address, or DNS name of the distribution point, - '&lt;port&gt;' is optional, - '&lt;path to crl file&gt;' _ _ _ is the path to the CRL file, conventionally with the .crl extension. | For example: http:// crl.example.org/pki/myCA.crl | add, show |
| enabled | Enables automatic download and periodic refresh of the CRL. Enabling will immediately trigger a CRL auto-download. When disabled, no CRL refresh/ updates will be performed, but existing CRLs are unaffected. | true, false | false | add, set, show |
| refresh-interval | Defines when CRL should be refreshed/updated. | If special enum value 'use-next-update' is specified, the next refresh time is defined by the current CRL next-update field. Otherwise, refresh interval is provided using the following syntax: '[xw] [xd] [xh] [xm] [xs] where: w(eeks), d(ays), h(ours), m(inutes), s(seconds). | Examples: 2w -- two weeks 5d 12h -- 5 days and 12 hours 1h 7m 30s -- 1 hour, 7 minutes and 30 seconds | add, set, show |
| next-update-time | Timestamp of next CRL update. | date-time in the format YYYY-MM- DDThh: mm:ssZ) see the set-time command for detailed information. | n/a | show |
| last-update-time | Timestamp of most recent CRL update. | date-time in the format YYYY-MM- DDThh: mm:ssZ) see the set-time command for detailed information. | n/a | show |
| last-update-result | Result of the most recent CRL update. | string length 0...255 | n/a | show |
