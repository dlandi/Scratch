## 6.63. crl

#### Command Description

This command is used to show one or all Certificate Revocation Lists (CRLs) presently on the system, and clear one or more installed Certificate Revocation Lists (CRLs) from the system. This includes manually downloaded CRLs as well as those automatically retrieved from a CRL Distribution Point (CDP).

#### Command Syntax

```
clear [-f] crl [[clear-target=]<value>] [crl-name=]<value>
show crl-<name> [issuer] [crl-number] [issuing-distribution-point-uri] [effective-date] [next-update] [signature-key-type]
[signature-hash-algorithm] [type] [status] [last-used-time] [associated-cdp] [downloaded-from-uri]
show crls
```

#### Examples

This example shows how to delete crl-myCA-1:

```
clear crl single-crl myCA-1
```

This example shows how to purge all invalid CRLs:

```
clear crl purge-invalid-crls
```
