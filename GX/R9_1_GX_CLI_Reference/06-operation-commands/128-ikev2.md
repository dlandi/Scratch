## 6.128. ikev2

#### Command Description

This command is used to set ikev2.

#### Command Syntax

```
set ikev2 [data-path-encryption-san-ike-id-match <value>]
show ikev2 [data-path-encryption-san-ike-id-match]
```

#### Command Usage Details

**Table 343: ikev2 Command Usage**

| Section | Description |
| --- | --- |
| Access Mode | Operational mode, Candidate Configuration mode |

#### Command Parameters

**Table 344: ikev2 Command Parameters**

| Parameter | Description | Values | Default | Used in |
| --- | --- | --- | --- | --- |
| data-path-encryption-san-ike-id-match | A global, L1 encryption-specific policy that indicates whether the NE must validate Certificate subject alternate name to match the IKE ID (OPT-IN) or not (OPT- OUT)."; | match, ignore | n/a | set, show |

#### Examples

This example shows how to set ikev2:

```
set ikev2 data-path-encryption-san-ike-id-match match
```
